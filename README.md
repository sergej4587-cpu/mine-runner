# Mine Runner

Игра в жанре Lode Runner (оригинальные персонажи и уровни). Папка `www` — сама игра (HTML5, работает в браузере и как PWA).

APK собирается автоматически в GitHub Actions: вкладка **Actions → Build APK → Run workflow**,
готовый `app-debug.apk` скачивается из раздела **Artifacts** (`mine-runner-apk`).
